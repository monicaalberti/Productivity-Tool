# SETTING UP STUDYWEAVE FRONTEND   

The frontend of the StudyWeave platform is a React.js application. To set it up and start it locally, follow the steps below.

## Installing dependencies:
1. Once you open the code in your chosen IDE, navigate to the `/frontend` directory;
2. Install all dependencies by running `npm install`.

## Starting the application:
3. Run `npm start`;
4. View your application in your default browser.
